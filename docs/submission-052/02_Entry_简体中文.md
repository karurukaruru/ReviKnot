**项目名：** PatchCourt — AI Agent Compatibility Guardian（AI智能体兼容性卫士）

**一句话：** 把悄悄发生的智能体回归问题，变成可检查的证据和可复用的CI测试。

**赛道：** Coding and Agentic Engineering（编程与智能体工程）

## 为什么做

工具已经执行，下一条模型请求却忘了它们。

SDK适配器可能悄悄丢失工具调用ID、参数或图片，同时仍然产生合法的Python和JSON。成功安装软件包，不能证明智能体下一步仍然收到相同含义的信息。PatchCourt把这层隐藏的消息合同展示出来，并要求候选修复通过独立验证。

## 它做什么

PatchCourt帮助开发者检查智能体与SDK交界处的消息变化。它比较原始消息与实际序列化结果，展示丢失的含义并生成证据报告。它区分保持一致、发现缺陷、不支持的输入和需要人工复核的情况。

诊断之后还有可继续使用的结果。开发者可以显式捕获一次适配器事务，把同一份真实输入导出成独立CI门禁。保存的坏结果会让测试失败；以后重新捕获的候选结果，必须保留冻结输入和适配器身份。生成的测试包含已审查检查器的源码和许可证，只用Python标准库即可运行。它检查用户提供的捕获数据，不会暗中执行或独立认证未来的SDK。

修复流程让模型提出受限的字段映射，再由独立检查器验证。故意破坏映射后必须被拒绝，随后实际开发模型会话调用两个固定的本地库存工具。已保存的成功开发流程恢复出经过核对的结果 **21**。模型生成的Python不会执行。

## 怎么实现

程序由Python语义比较器、主动选择的事务记录、本地HTML工作台、独立回归导出和带源码/环境身份的证据组成。复用旧修复时仍须重新验证。持久化调用账本在发送请求之前预留次数，因此失败请求也会留在预算和证据里。

示例复现了已署名的历史问题：LangChain NVIDIA工具调用序列化丢失，以及CrewAI/Gemini图片格式化丢失。另有独立执行的SDK升级实验，在共同依赖版本固定的条件下运行两个真实安装的NVIDIA SDK版本。每份输出都与原始输入比较：两个版本即使错得一样，也只能得到 **NEEDS_REVIEW（需要复核）**，不能得到兼容通过。

0.5.2已使用真实 **DeepSeek Flash** 请求，以及 **Tavily** 对允许列表内官方文档的检索。首次完整流程通过，包含3次模型请求，供应商报告4094个token。随后同一身份命中已保存修复，省去了重新提案的请求，但仍重新验证8项检查、拒绝被破坏的修复，并再次完成工具任务：2次模型请求、655个报告token。这是两次实际观察，不是普遍节省比例。原始报告保存在 `evidence/development-052`。

另一组评测保留 **PARTIAL（部分完成）**，原因是第二轮原版ACV基线回复不完整。直接模型与Tavily辅助两组，在同样12个开发者编写样例的两次重复中，各自匹配了24个预期结果中的18个。没有观察到检索提升；这也不是独立留出的盲测。更早GLM实验和失败尝试保留原标签。这些开发运行仍不能替代比赛指定平台实测。

后续v2协议明确OpenAI/LangChain规范化合同与判定顺序，保留原有冻结样例和标签，并允许配置输出预算。这些代码修改不等于已经测得v2真实运行结果；原有v1 PARTIAL记录保持不变。

计划中的比赛路径使用 **Nebius Token Factory** 提供的NVIDIA Nemotron模型，提出受限修复并参与实际工具会话。本审核节点仍缺少可用Nebius访问，因此最终推理尚未执行。模型列表查询、SDK本地执行和其他供应商的模型完成记录，属于不同类别的证据。

## 难点和已完成的价值

最难的是界定什么配得上“通过”。两个相同输出可能共有一个缺陷；脱敏可能遮住差异；看起来合理的修复可能是错的；HTTP成功也不能证明工具调用合同没有被破坏。

因此，PatchCourt保留失败尝试、源码与环境身份、请求记录、独立控制和明确的适用范围。基于捕获输入生成的门禁，可以把发现的问题留在开发者自己的CI里。工作台断线恢复会查询已有运行状态，避免误导用户再次发送推理请求。

## 给谁用，解决什么问题

目标用户是评估SDK升级或排查工具会话失败的智能体开发者。他们需要一个小而可复现的合同、一份可检查的解释，以及可以保留的回归测试。PatchCourt已在审查过的适配器和一个受控应用捕获上演示这条流程。它不声称已有生产用户、覆盖全部框架，或已经测得故障率下降。

## 学到了什么，下一步是什么

兼容性是关于含义的合同，不只是两个软件包输出是否一样。允许独立验证器否决模型，并保留被否决的尝试，模型辅助才更有用。

下一步是完成真实Nebius/NVIDIA执行，并扩展经过审查的应用边界。本版本不承诺任意仓库自动插桩、生产环境自动修复或通用视觉任务保证。保留图片字节证明的是序列化行为，不等于完成实际视觉模型任务。

## 既有工作和署名

PatchCourt基于比赛开始之前的Agent Code Validator v0.2.0。原有扫描器、有界只读工具、命令行和MIT许可证继续保留。比赛期间增加了语义边界检查、历史缺陷复现、已安装SDK比较、受限修复验证、真实开发模型工具流程、事务捕获、独立CI门禁和证据工作台。源码包中的 `COMPETITION_CHANGELOG.md` 记录这些改动。

历史缺陷来源于LangChain NVIDIA issue #387和CrewAI issue #8434，不被包装成新发现。上游源码与署名按适用许可证保留。
