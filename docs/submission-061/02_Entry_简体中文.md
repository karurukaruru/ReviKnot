# ReviKnot — 编码 Agent 可以调用的兼容性检查

SDK 或适配器改动后，工具可能仍能执行，但调用 ID 丢失会让返回结果接不上；有效 JSON 也可能把嵌套布尔值改成数字。两个版本输出一样，不等于它们保留了原输入。

ReviKnot 对照原始输入检查捕获消息，返回具体字段位置。四个本地 MCP 工具分别检查消息边界、检查录制、比较录制版本、导出标准库回归门禁。适合在修改消息序列化或升级 SDK 后、准备合并前按需调用。由宿主 Agent 决定触发时机，没有声称后台持续监控或自动接管编辑器。

NVIDIA 模型工作流负责提出受限声明式修复，由独立验证脚本检查，再运行真实模型/工具对话。记录在案的 0.6.0 验收使用 Nebius Token Factory 上的 NVIDIA-Nemotron-3-Nano-30B-A3B：4 次调用、5,992 报告 token、8 项检查、破坏修复被拒、两工具健康检查得到 21。3×7 是通路诊断，不是产品主功能。

MCP 已用官方 SDK 2.3.0 的真实 stdio 客户端跑通：发现 4 个工具、调用 6 次。受控退款 Agent 包含两个工具、嵌套布尔、Unicode、币种及审批标志；丢 ID 的版本失败，保持原语义的版本通过，false 改成 0 的版本失败。两个同样损坏的版本仍是 NEEDS_REVIEW。导出的独立门禁在隔离 Python 中呈现 1/0/1 退出码。示例不连接真实客户或支付；独立安装 NVIDIA SDK 的执行证据另列。

0.6.1 是当前源码与应用发布版本，主要改进安装器、默认 MCP 依赖和客户端接入。模型与 MCP 实测数字仍明确归属于 0.6.0 验收，没有冒充 0.6.1 重新调用付费模型。

价值是保留 Agent 真正依赖的接口约束，并留下后续开发者和 CI 能复验的门禁。MCP 检查不需要模型密钥、不调用付费 API、不导入任意项目代码。提供编辑器接入说明；实际集成验收使用官方 MCP 客户端，不冒充已录制特定编辑器会话。

范围是审查过的文本/工具消息，不是万能代码审查或沙箱。历史失败记录与小型 PARTIAL 评测保留；不声称通用准确率或成本优势。后续可以扩展独立适配器案例与宿主使用体验。
